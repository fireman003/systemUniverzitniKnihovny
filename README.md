# systemUniverzitniKnihovny
Semestrální projekt BPC-PC1M (FEKT VUT Brno): konzolová aplikace pro evidenci univerzitní knihovny. Správa knih a čtenářů, výpůjčky a vrácení s kontrolou dostupnosti, vyhledávání podle názvu a autora, ukládání a načítání dat ze souboru, textové menu a ošetření chybných vstupů. Týmový projekt 4 studentů.
